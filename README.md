# TMJ Pen

## Overview

TMJ Pen is a portable therapeutic device prototype designed to help manage jaw muscle tension and discomfort associated with temporomandibular joint (TMJ) disorders. The device integrates adjustable heat, gentle vibration, and targeted acupressure in a compact, ergonomic design.

## Key Features

* Adjustable heat functionality
* Gentle vibration mechanism
* Targeted acupressure tip
* Ergonomic, portable design
* Custom-designed casing using SolidWorks
* 3D-printed prototype using a Bambu Lab 3D printer

## Design and Development

The project focuses on product design, mechanical integration, ergonomic considerations, and rapid prototyping to explore an accessible approach to jaw muscle relaxation.

## Technologies and Tools

* SolidWorks
* 3D Printing
* Bambu Lab
* Mechanical Product Design

## Project Status

Prototype development.

## Disclaimer

This is a prototype and is not a clinically validated medical device. Its safety and effectiveness for treating TMJ disorders have not been established. It is not a substitute for professional medical advice or treatment.
